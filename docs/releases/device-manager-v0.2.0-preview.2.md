# Selfrionette Device Manager v0.2.0-preview.2

**Windows向けプレビュー版**

入力確認で選んだ接続先をFirmware更新へ引き継ぎ、一時停止・再接続と、新版／保管7ch版の選択を追加しました。

> **software preview（実機認定なし）：** 実機の書込み・設定保持・校正と、Windowsの実DPI切替は未検証です。受信値のcount、N単位、正規化入力は別の値です。

## 今回のハイライト

### 選んだ装置を、そのまま更新対象へ

「Firmware更新」を開くと、ポートを開かずに候補を列挙します。入力確認で選んだ装置を引き継ぎ、「受信を停止して更新へ」で接続を解放してから検査します。

### アプリを閉じずに一時停止・再接続

「一時停止（接続を解放）」でArduinoなど他のツールへ接続を渡せます。再開時はUSB情報を再照合し、既知の個体IDが異なる場合は停止します。起動時に自動接続しません。

### 新版と保管7ch版を選択

「新版（個体設定・個人校正対応）」と「旧版（初期保管ソース）」を別々にビルドして同梱します。保管版は先輩の実機に入っているFirmwareと同一とは確認されていません。

## 追加された機能

### 接続と入力確認

- 最後に明示選択したUSB候補をローカル設定に保存します。COM番号だけで個体を認定しません。
- 見つからない装置も再接続待ちとして残し、再検索できます。
- 旧版の入力確認は校正不要です。「受信可能・設定未確認」と表示します。
- 新版の補正入力は Firmware → 装置設定 → 個人校正 → 保存した入力設定の順に準備します。

### Firmware更新と確認

- 新版と保管版それぞれのmanifest・画像をアプリのビルドへhashで結び付けます。
- 対応基板はPro Micro 5V 16MHz／ATmega32U4です。系統・基板・schema・protocol・HEXの不一致を拒否します。
- application flash全域を固定AVRDUDEで比較してからbootloaderを終了します。EEPROM、fuse、bootloaderは書き換えません。
- 保管版は「画像確認済み、ID・版情報は取得不可、設定保持は未確認」と区別します。旧版の7ch受信だけで画像や版を認定しません。
- 退避した既知のID・設定を保持し、新版へ戻した際に照合します。

## 操作性の改善

- 接続先とFirmwareのラベルを選択欄の上へ配置し、狭い表示で折り返すようにしました。
- 書込み前に、次に必要な操作とボタンが無効な理由を表示します。
- 出典や装置情報は詳細欄で確認できます。未確認事項の説明を常時重ねて表示しません。
- 一時停止後は現在値を消し、過去の履歴を更新停止として保持します。再接続時は新しい履歴区間にします。

## 修正された不具合

- 未識別の初期保管版への情報照会が意図せずゼロ点調整になる問題を修正しました。通常の入力確認は受信専用、明示照会とsetup/updateは安全な?2 / ?3だけを使います。応答しないpreview.1には初回更新を案内します。
- 新版で停止した後に別の旧版を使った場合、最後の接続先へ再接続するようにしました。停止・再開で以前の中立値や入力有効状態を復元しません。

- 入力確認で受信中でも更新対象が空になる問題を修正しました。
- 再検索で有効な選択が空欄へ戻る問題を修正しました。
- 無効な主操作ボタンが有効に見える配色を修正しました。
- 接続情報の変更後に古い更新計画を使わないよう、backendでも計画を失効させます。
- 受信失敗後も選択候補を保持し、アプリの再起動なしで再接続できます。

## インストールと更新

旧版を終了し、新しいインストーラーを実行してください。保存記録を残す場合はアプリデータを削除しないでください。ZIP版は別フォルダーへ全ファイルを展開します。

**アプリの更新とFirmwareの書込みは別操作です。** インストールやアプリ起動だけでは装置へ接続・書込みません。保管7ch版では装置設定・個人校正を利用できません。新版の機能を使う場合は新版へ戻し、ID・設定を確認してから新しい中立値を取得します。

詳しくは[導入手順](https://github.com/Xpotato1024/Selfrionette-Device/blob/{{SOURCE_SHA}}/docs/operations/device-manager-distribution.md)を参照してください。

## 開発者向けの変更

- schema 2のFirmware系統情報と上限2件の固定catalogを追加しました。既存のmodern schema 1も検査できます。
- 保管7chソースはbyteを変更せず、独立した固定PlatformIO設定でcompileします。採用元は初期の`loadcell_7ch_legacy`、`isLeader=true`の7ch構成です。後の整理候補`loadcell_7ch_pro_micro`は参照専用で、両保管treeは変更しません。
- package、installer、portableの検証とsource fingerprintに両系統を含めます。
- 接続所有の排他、更新計画の失効、個体差し替え、両方向の更新、中断復旧をmockで検証します。

## 既知の制限と注意事項

- 実機受入は未実施です。保管版は起動時に既存のゼロ点取得を行うソースで、品質・ID・版情報の照会はありません。
- 保管版へ切り替えた間の設定保持は未確認です。退避記録を削除せず、新版へ戻した際の照合が必要です。
- 途中で画像の全域確認が完了しなかった場合、受信や利用者の承認だけでは復旧済みにしません。元の装置を手動でbootloader待機状態にし、固定ツールの確認操作が必要です。自動reset・再書込みはしません。
- 未署名のWindowsプレビューです。実DPI切替、クリーンPC、実機の連続運転は別の受入対象です。

## 検証と配布情報
