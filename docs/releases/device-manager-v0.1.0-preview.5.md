# Selfrionette Device Manager v0.1.0-preview.5

**Windows向けプレビュー版 — 2026年10月14日**

SelfrionetteをPCへ接続し、7チャンネルの入力を確認するためのWindowsデスクトップアプリを、GitHub Releasesからダウンロードできるようにしました。

このバージョンでは、**接続する機器の選びやすさ、数値の読みやすさ、実機操作と開発用試験の分離**を中心に改善しています。

> **プレビュー版について：** 実機の入力監視と診断を目的とした開発途中のリリースです。物理校正、デバイスへの設定保存、Firmware書込み、ロボット制御はまだ提供しません。対応する実機すべてでの動作確認も完了していません。

## 今回のハイライト

### Selfrionetteを選びやすく

接続先を長いCOMポートのドロップダウンから選ぶ方式を見直しました。新しい「接続先を選ぶ…」では、USBのVID/PIDなどから**対応基板の候補**を上位に表示します。

候補に含まれない機器も「その他のポートも表示」から選択でき、接続前に選択したUSB情報をもう一度照合します。COM番号だけで個体や左右を推定しません。

### 数値が動いても、画面は動かない

7チャンネルの表示を固定幅の数値ペインにまとめ、符号・桁数・小数部が変わっても列位置と小数点位置が動かないようにしました。受信値が更新されても行を作り直しません。

### Windowsらしい操作画面へ

標準タイトルバーと**ネイティブメニュー**を使い、上部には普段必要な操作だけを残しました。「デバイス」「表示」「ヘルプ」から低頻度の機能へアクセスできます。

## 追加された機能

### 入力の確認と診断
- 対応する旧形式・Protocol v2の7chシリアル入力を受信し、現在値を表示できます。
- 受信状況、個体情報の応答、Firmwareバージョン、Protocolを区別して扱います。
- 選択した一台だけに明示的に接続します。USBポートを無差別に開く処理はありません。
- 対応する機器では、利用者が選択した場合に限り`info`を送信できます。旧Firmwareの受信確認も残しています。

### 入力履歴の表示
- 左のch行を選ぶと、右側の履歴も同じchへ切り替わります。
- 直近30秒・最大200表示点の履歴を表示し、縦軸を自動／固定で切り替えられます。
- 受信が止まった際は現在値を`—`へ変更し、過去の履歴は「更新停止」として残します。
- 新しい接続の履歴と混ざらないよう、接続セッションを区別します。

### 開発者向け機能
- 合成試験を通常画面から取り除きました。
- `ヘルプ → 開発者向け機能を有効にする…`から開発者モードを起動し、`開発 → 合成試験`で切り替えられます。
- CLIの`--developer-mode`と`--developer-mode --synthetic`にも対応します。
- 開発者モードの状態は再起動後に引き継ぎません。通常モードでは合成試験の内部コマンドも拒否します。

## 操作性の改善

- **受信中も操作可能に：** 読み取り処理中に押された切断操作を落とさず、読み取り終了後に処理するようにしました。
- **調整は一手順ずつ：** 横の作業タブと左の番号付きステップを使い、現在の工程だけを表示します。
- **不要な重複表示を削減：** 製品名や状態の説明を何度も表示せず、情報の重要度に合わせて配置しました。
- **確認操作を明確化：** 再取得・再確認・やり直しなど、実際に起こる操作をボタン名で区別しました。
- **履歴と現在値を分離：** 過去の値を新しい測定値として表示し続けないようにしました。

## 修正された不具合

- 旧版から更新する際、インストール前のアンインストーラーが`Error launching installer`で停止する場合があった問題を修正しました。
- 数値の桁数や符号によって、列の配置や行の高さが変わる問題を修正しました。
- 画面の切替・過去記録の閲覧だけで調整状態を変更しないよう、操作の境界を整理しました。
- 対象切替や処理の遅延により、古い状態の操作が新しい対象へ適用されないようにしました。

## インストールと更新

新規利用の場合は、上のインストーラーを実行し、スタートメニューから起動してください。以前のプレビュー版を利用している場合は、アプリを終了してから新版のインストーラーを起動します。

更新中にアプリデータの削除を尋ねられた場合、保存済み記録を残すなら削除しないでください。ZIP版は別フォルダーへ展開して比較できます。

詳しくは[使用者向けの導入手順](https://github.com/Xpotato1024/Selfrionette-Device/blob/main/docs/operations/device-manager-distribution.md)を参照してください。

## 開発者向けの変更

- Rust側の接続セッション・対象照合・通常／開発者モードの実行制限を整理しました。
- CIを変更範囲に応じた高速検証と配布検証に分離しました。画面修正のたびにインストーラーを再生成する必要はありません。
- Windowsの配布バイナリは一度ビルドし、別の検証環境でインストール・更新・起動・アンインストールを確認する構成です。
- clone・ローカルブランチでの開発用ビルド手順は引き続き利用できます。
- 装置内の不揮発設定とFirmware更新については契約・基礎処理の設計を進めていますが、実機へ書き込む機能は本リリースに含まれません。

## 既知の制限と注意事項

- **実機校正・設定保存・Firmware更新は未実装です。** 合成試験が成功しても、実機が校正済み・使用可能になったとは判断できません。
- **一度に監視できるのは一台です。** 二台同時監視や、個体IDに基づく左右の自動割当は今後の対象です。
- USB情報による候補表示は、Selfrionetteの個体認証ではありません。同じ基板を使う別用途の機器が候補になる場合があります。
- このバージョンは未署名です。Windowsで発行元の警告が表示される場合があります。
- Windows 11 x64以外、実際のDPI切替、WebView2未導入のクリーンPC、大学の実機での連続受信については受入試験を完了していません。
- 画面の受信値はFirmware処理後の値です。物理単位のN、ロードセルの極性、品質を検証済みとみなすことはできません。
